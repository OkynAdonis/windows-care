# Briefs visuels Windows Care

Ces supports peuvent etre conçus dans Canva, Figma, Photoshop ou un outil similaire. Utiliser `site/assets/windowscarelogobck.png` comme logo principal et `site/assets/TE.png` seulement pour signer TECH EXCHANGE.

## Regles communes

- Palette : encre `#13252B`, turquoise `#0B6670`, vert lime `#C9E85B`, fond clair `#F3F5F1`, blanc `#FFFFFF`.
- Typographie : Manrope pour les titres et le texte ; DM Mono pour les numeros, versions et donnees techniques.
- Toujours afficher `Version de test publique` tant que la validation Windows 10/11 en VM n est pas terminee.
- Ne pas promettre une acceleration garantie, une securite totale ou une reparation sans risque.
- Utiliser la vraie capture `site/assets/report-preview.png` pour illustrer un resultat. Ne pas presenter le score de demonstration `86/100` comme une mesure reelle.
- Garder une marge de securite de 5 % autour du logo. Ne pas l etirer, recolorer, incliner ni poser sa version sombre sur un fond trop sombre.
- Lien officiel : `https://okynadonis.github.io/windows-care/`.

## Affiche principale — reseaux sociaux

Format source : 1080 × 1350 px. Prevoir aussi une exportation carree 1080 × 1080 px.

Composition conseillee :

1. Logo Windows Care en haut, largeur proche de 75 %.
2. Titre : `Votre PC, plus clair.`
3. Sous-titre : `Diagnostiquer · Reparer · Maintenir · Optimiser`.
4. Visuel central : capture du rapport dans un cadre simple, avec le libelle `Exemple de rapport local`.
5. Trois preuves courtes : `29 actions guidees`, `Mode simulation`, `Rapports locaux`.
6. Bouton visuel : `Tester la preversion`.
7. Bas de page : URL, `Windows 10/11`, `Version de test publique`, signature TECH EXCHANGE.

Texte de publication :

> Windows Care rassemble diagnostic, maintenance et outils de restauration dans un menu local pour Windows 10 et 11. La preversion publique est disponible : commencez par le mode simulation et partagez vos retours.

## Story — lancement rapide

Format : 1080 × 1920 px. Garder les textes essentiels entre 250 et 1650 px de hauteur pour eviter les zones masquees par les interfaces sociales.

- Ecran 1 : logo et `29 actions Windows dans un seul outil local`.
- Ecran 2 : capture du menu et `Choisissez une action guidee`.
- Ecran 3 : capture du rapport et `Comprenez le resultat avant d agir`.
- Ecran 4 : `Mode simulation disponible` puis URL et QR code.

Sous le QR code, conserver aussi l URL en texte. Tester le QR code depuis un second telephone avant publication.

## Carrousel pedagogique — cinq pages

Format : 1080 × 1350 px par page.

1. `Windows Care, a quoi ça sert ?` avec le logo.
2. `Diagnostiquer` : score indicatif, couverture des mesures et rapport local.
3. `Maintenir` : nettoyage et reparation avec confirmations et limites expliquees.
4. `Garder le controle` : mode simulation et sauvegardes pour les reglages pris en charge.
5. `Tester et signaler` : URL, QR code et lien GitHub pour les anomalies.

## Visuels encore utiles a produire

- Une capture propre du menu montrant les 29 choix et le statut de session standard ou administrateur. La capture actuelle est ancienne et n affiche que les choix 1 a 15.
- Une capture de sauvegarde et restauration sur une VM jetable, apres validation reelle.
- Une courte video verticale de 15 a 25 secondes : ouverture, mode simulation, score, rapport. Aucun changement systeme reel pendant l enregistrement.
- QR code haute resolution produit : `site/assets/windows-care-qr.png`, 1000 × 1000 px, correction H et marge blanche. Le décodage automatisé confirme l URL officielle ; le test de lecture sur Android et iPhone reste à faire avant impression ou campagne.

## Checklist avant export

- Logo net et non deforme.
- Mention de preversion visible.
- URL exacte et QR code teste.
- Capture marquee `Exemple` si elle montre un score.
- Aucun nom de compte, nom de machine, adresse IP, chemin personnel ou journal complet visible.
- Contraste lisible sur telephone ; texte principal d au moins 36 px pour une publication 1080 px.
- Export PNG pour les reseaux, PDF impression pour l A4, fichier source editable conserve.
