21 actions,
un système plus clair.

Ce guide explique chaque choix du menu avant son lancement. Les actions qui modifient Windows demandent une confirmation et créent une sauvegarde lorsque cela est nécessaire.

Droits administrateur requis pour les actions système · Mode simulation disponible

01 / Le menu complet
01

État système

Affiche la version de Windows, le dernier démarrage, l’espace libre, le plan d’alimentation et les interfaces réseau actives.

DIAGNOSTIC · SANS MODIFICATION
02

Score de santé du PC

Calcule un score sur 100 à partir du stockage, du démarrage, de Defender, du pare-feu et de la connectivité réseau.

DIAGNOSTIC · RECOMMANDATIONS
03

Rapport HTML de santé

Génère un rapport consultable dans un navigateur avec le score, les catégories mesurées et l’identité TECH EXCHANGE.

RAPPORT · FICHIER LOCAL
04

Assistant de réparation

Propose un parcours selon le problème : PC lent, Internet lent, Windows Update, disque presque plein ou confidentialité.

ASSISTANCE · GUIDÉE
05

Nettoyage système

Supprime les fichiers temporaires, les éléments du Prefetch et vide la corbeille après confirmation.

MAINTENANCE · SAUVEGARDE
06

Réparation Windows

Exécute DISM pour réparer l’image Windows, puis SFC pour vérifier et restaurer les fichiers système.

RÉPARATION · OPÉRATION LONGUE
07

DNS Google

Configure 8.8.8.8 et 8.8.4.4 sur une interface réseau active choisie par l’utilisateur.

RÉSEAU · MODIFICATION
08

DNS Cloudflare

Configure 1.1.1.1 et 1.0.0.1 pour utiliser les résolveurs DNS publics de Cloudflare.

RÉSEAU · MODIFICATION
09

Réinitialisation réseau

Vide le cache DNS et réinitialise Winsock ainsi que la pile TCP/IP. Un redémarrage peut être nécessaire.

RÉSEAU · REDÉMARRAGE POSSIBLE
10

Confidentialité et télémétrie

Désactive certaines tâches de télémétrie et applique des politiques Windows de confidentialité documentées.

CONFIDENTIALITÉ · SAUVEGARDE
11

Confidentialité Windows Search

Réduit la recherche web, les fonctions cloud et certaines suggestions connectées de Windows Search.

CONFIDENTIALITÉ · SAUVEGARDE
12

Profil Bureautique

Active un profil orienté stabilité et performance quotidienne pour le travail et les usages courants.

PROFIL · PERFORMANCE
13

Profil Gaming

Active le plan Performances optimales pour privilégier la réactivité pendant les sessions de jeu.

PROFIL · PERFORMANCE
14

Profil Portable

Active le plan Équilibré pour préserver l’autonomie et limiter la consommation d’un ordinateur portable.

PROFIL · AUTONOMIE
15

Profil Confidentialité

Regroupe les réglages de télémétrie et de Windows Search dans un parcours unique.

PROFIL · SAUVEGARDE
16

Réparation Windows Update

Arrête les services concernés, renomme les caches SoftwareDistribution et catroot2, puis relance les services.

RÉPARATION · SAUVEGARDE
17

État des disques

Affiche les disques physiques, leur état de santé, leur type et leur statut opérationnel.

DIAGNOSTIC · SANS MODIFICATION
18

Rapport des programmes au démarrage

Exporte les programmes lancés avec Windows dans un rapport local pour faciliter le tri et l’analyse.

RAPPORT · FICHIER LOCAL
19

Maintenance hebdomadaire

Planifie un rapport de santé hebdomadaire en mode simulation afin de surveiller le système sans le modifier.

PLANIFICATION · SANS MODIFICATION
20

Restaurer une sauvegarde

Réimporte une sauvegarde de registre et restaure le plan d’alimentation enregistré par une session précédente.

RESTAURATION · CONFIRMATION
21

Mode simulation

Permet de parcourir les actions et leurs confirmations sans appliquer de modification à Windows.
