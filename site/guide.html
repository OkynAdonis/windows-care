01 / Le menu complet

36 actions disponibles.

01

État système

Affiche la version de Windows, le dernier démarrage, l’espace libre, le plan d’alimentation et les interfaces réseau actives.

DIAGNOSTIC · SANS MODIFICATION
02

Score de santé du PC

Présente cinq mesures avec leurs critères et recommandations. Les données indisponibles sont exclues ; le score nécessite au moins trois mesures. Le réseau local ne constitue pas un test Internet.

DIAGNOSTIC · RECOMMANDATIONS
03

Rapport HTML de santé

Génère un rapport local avec le score, la couverture des mesures, leurs limites et les recommandations. Les données indisponibles sont indiquées ; chaque rapport est conservé séparément.

RAPPORT · FICHIER LOCAL
04

Assistant de réparation

Propose un parcours selon le problème : PC lent, Internet lent, Windows Update, disque presque plein ou confidentialité.

ASSISTANCE · GUIDÉE
05

Nettoyage système

Supprime les fichiers temporaires et vide la corbeille après confirmation. Le Prefetch est conservé. Les fichiers supprimés ne sont pas récupérables par Windows Care.

MAINTENANCE · SUPPRESSION DÉFINITIVE
06

Réparation Windows

Exécute DISM puis SFC si DISM réussit. Un redémarrage peut être nécessaire. Windows Care ne fournit pas de retour arrière de cette réparation.

RÉPARATION · OPÉRATION LONGUE
07

DNS Google

Configure 8.8.8.8 et 8.8.4.4 sur une interface réseau active choisie par l’utilisateur.

RÉSEAU · MODIFICATION
08

DNS Cloudflare

Configure 1.1.1.1 et 1.0.0.1 pour utiliser les résolveurs DNS publics de Cloudflare.

RÉSEAU · MODIFICATION
09

Réinitialisation réseau

Vide le cache DNS et réinitialise Winsock et TCP/IP. Un redémarrage peut être nécessaire. Pas de restauration automatique de cette réinitialisation.

RÉSEAU · REDÉMARRAGE POSSIBLE
10

Confidentialité et télémétrie

Désactive certaines tâches de télémétrie et applique des politiques Windows de confidentialité documentées.

CONFIDENTIALITÉ · SAUVEGARDE
11

Confidentialité Windows Search

Réduit la recherche web, les fonctions cloud et certaines suggestions connectées de Windows Search.

CONFIDENTIALITÉ · SAUVEGARDE
12

Profil Bureautique

Active le plan Équilibré pour le travail quotidien. Le plan précédent peut être restauré avec le choix 22.

PROFIL · PERFORMANCE
13

Profil Gaming

Active le plan Performances optimales pour privilégier la réactivité pendant les sessions de jeu.

PROFIL · PERFORMANCE
14

Profil Portable

Active le plan Équilibré pour préserver l’autonomie et limiter la consommation d’un ordinateur portable.

PROFIL · AUTONOMIE
15

Profil Confidentialité

Regroupe les réglages de télémétrie et de Windows Search dans un parcours unique.

PROFIL · SAUVEGARDE
16

Réparation Windows Update

Conserve les anciens caches sous des noms uniques et rétablit les services auparavant actifs, même après un échec. Pas de restauration automatique des caches.

RÉPARATION · ANCIENS CACHES CONSERVÉS
17

État des disques

Affiche les disques physiques, leur état de santé, leur type et leur statut opérationnel.

DIAGNOSTIC · SANS MODIFICATION
18

Rapport des programmes au démarrage

Exporte les programmes lancés avec Windows dans un rapport local pour faciliter le tri et l’analyse.

RAPPORT · FICHIER LOCAL
19

Maintenance hebdomadaire

Génère un rapport chaque dimanche à 10 h lorsque le compte est connecté, y compris sur batterie. Le dossier de données choisi est conservé. Replanifier après déplacement du programme ; suppression avec -RemoveMaintenanceTask.

PLANIFICATION · SANS MODIFICATION
20

Restaurer une sauvegarde

Restaure la catégorie choisie : registre, services et tâches de confidentialité, DNS ou alimentation, après sauvegarde de l’état courant. Les anciennes sauvegardes partielles nécessitent une récupération manuelle.

RESTAURATION · CONFIRMATION
21

Mode simulation

Bloque les modifications système et les sauvegardes. Les diagnostics restent disponibles ; les journaux et rapports locaux peuvent être écrits.

PRUDENCE · RECOMMANDÉ AVANT ESSAI
22

Restaurer le plan après session

Rétablit manuellement le plan enregistré avant le premier changement de profil.

ALIMENTATION · RESTAURATION
23

Coûts énergétiques relatifs

Compare la consommation relative des plans. Il ne s’agit pas d’une mesure électrique ni d’un prix calculé.

INFORMATION · SANS MODIFICATION
24

Diagnostic réseau détaillé

Sépare la configuration des interfaces, la résolution DNS et la connexion HTTPS afin de localiser la panne.

DIAGNOSTIC · CONNEXION TESTÉE
25

Diagnostic Windows Update

Affiche les services essentiels, les dernières mises à jour et les raisons détectées d’un redémarrage en attente.

DIAGNOSTIC · SANS MODIFICATION
26

Pilotes en erreur

Recherche les périphériques dont Windows signale un code d’erreur. Aucun pilote tiers n’est téléchargé ou installé.

DIAGNOSTIC · GESTIONNAIRE DE PÉRIPHÉRIQUES
27

Rapport batterie

Crée le rapport HTML officiel de Windows lorsqu’une batterie est détectée.

RAPPORT · ORDINATEUR PORTABLE
28

Point de restauration Windows

Demande à Windows de créer un point de restauration avant des modifications. La Protection du système doit être disponible et activée.

PRUDENCE · MODIFICATION CONFIRMÉE
29

Dossier de support

Regroupe diagnostic, santé, pilotes, mises à jour, démarrage et journaux récents. Relire les informations locales avant tout partage.

ASSISTANCE · DONNÉES À RELIRE
30

Centre de réparation des applications

Vérifie WinGet et ses sources, liste les mises à jour, puis permet de mettre à jour ou réparer une application choisie par son identifiant exact. Chaque modification demande une confirmation et aucune mise à jour globale n’est lancée automatiquement.

APPLICATIONS · WINGET · CONFIRMATION
31

Diagnostic système avancé

Analyse CPU, mémoire, disques, processus lourds, erreurs critiques et historique de stabilité. Un rapport JSON local peut regrouper les résultats pour l’assistance.

DIAGNOSTIC · LECTURE SEULE
32

Centre Microsoft Defender

Affiche l’état de la protection et l’historique des menaces, met à jour les signatures et lance une analyse rapide, complète ou hors ligne. Le redémarrage requis par l’analyse hors ligne est annoncé avant confirmation.

SÉCURITÉ · CONFIRMATION
33

Diagnostic Windows progressif

Enchaîne DISM CheckHealth, DISM ScanHealth, SFC VerifyOnly et CHKDSK Scan sans réparer automatiquement. La réparation DISM/SFC reste un choix séparé et confirmé.

WINDOWS · DIAGNOSTIC PAR ÉTAPES
34

Diagnostic réseau avancé

Examine la configuration IP, les routes, les proxys, la latence, les réponses DNS et les interfaces physiques ou virtuelles avant toute réinitialisation.

RÉSEAU · LECTURE SEULE
35

Outils Microsoft Sysinternals

Vérifie ou installe la suite officielle avec l’identifiant WinGet exact Microsoft.Sysinternals, puis ouvre Autoruns, Process Explorer, TCPView, RAMMap ou Sigcheck. Installation et lancement demandent confirmation.

MICROSOFT · OUTILS OPTIONNELS
36

Premiers secours

Guide le diagnostic selon quatre symptômes : PC lent, Windows instable, réseau défaillant ou suspicion de problème de sécurité. Les réparations restent séparées.

ASSISTANT · DIAGNOSTIC D’ABORD
