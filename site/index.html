01

Sur le poste concerné

Décompressez Windows Care sur l’appareil à dépanner et lancez le programme. Les contrôles portent sur ce poste Windows 10 ou 11.

02

Deux points d’entrée

La cause reste à trouver ? Utilisez les diagnostics. Votre audit est déjà fait ? Accédez directement à l’un des 36 choix du menu.

03

Une action ciblée

Choisissez l’intervention qui répond au constat, consultez son effet et confirmez les modifications. Un symptôme ne déclenche pas une réparation automatique.

04

Un résultat à vérifier

Relancez le contrôle utile et reproduisez le problème initial. Les journaux et rapports locaux vous aident à documenter l’intervention.

03 / Utiliser Windows Care en intervention

Windows Care.
Clair, local, utile.

Extrayez tous les fichiers du ZIP dans le même dossier sur le poste concerné. Le lancement habituel avec SCRIPT_TOOL.bat demande les droits administrateur. Pour ouvrir le menu sans élévation, lancez SCRIPT_TOOL.bat -StandardUser ; les actions système qui exigent ces droits seront refusées. Le mode -DryRun permet de découvrir les actions sans modifier les réglages système.

04 / Questions de terrain

À qui s’adresse Windows Care ?

Aux techniciens de maintenance et de support qui interviennent directement sur un poste Windows. Le programme rassemble les outils ; le technicien interprète les résultats et choisit l’intervention.

Faut-il installer un agent ?

Le programme se lance depuis le ZIP extrait, sans installateur Windows Care. Gardez ses fichiers ensemble. Certaines fonctions utilisent Internet et les outils Sysinternals sont optionnels.

Le diagnostic est-il obligatoire ?

Non. Si votre audit est déjà fait, choisissez directement une action. Les parcours par symptôme servent à vous orienter lorsque la cause reste à déterminer.

L’outil trouve-t-il toutes les pannes ?

Il présente les anomalies détectables par ses contrôles et des pistes à examiner. Une mesure indisponible reste une inconnue. Le score de santé ne certifie pas qu’un PC fonctionne parfaitement.

Peut-on annuler une intervention ?

Les réglages sauvegardés de confidentialité, DNS et alimentation disposent d’une restauration. Le nettoyage, DISM/SFC et la réinitialisation réseau n’ont pas de retour arrière dans Windows Care. Le guide précise les limites de chaque action.

Comment garder une trace ?

Utilisez le rapport HTML (03), les journaux ou le dossier de support (29). Relisez les informations du poste avant tout partage. Windows Care est développé par TECH EXCHANGE.
